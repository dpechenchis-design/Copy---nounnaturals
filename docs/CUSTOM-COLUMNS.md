# Custom columns: parked design

Status: not built. The owner decided on November 14, 2026 to keep **fixed columns per space** for now. He asked to keep these notes in case we go back to custom columns as we use the app (for example if Daryna, who runs the content team, asks for them).

## Why fixed columns for now
The content team's Notion showed what free columns do over time:
- The same thing gets two names ("Edited video" and "Video Edited").
- Free typing where a list belongs ("TT", "TikTok", "Tik Tok" become three values).
- Weeks drift apart (a column added in Week 2 is missing in Week 1).
- A hand typed column contradicts reality (Publishing date was empty on every row; a typed status can say posted when nothing was posted).

In Noun ART the app fills what it knows (status, shot, raw clips, edited video, publishing date) and platforms show as icons, so most of those columns never need typing.

## If we add custom columns later: the six rules
1. **Two kinds of columns.** System columns (Title, Day, Status, Shot, Raw clips, Edited video, Platforms, Publishing date) are filled by the app. They can be renamed, hidden and reordered, never deleted.
2. **Every custom column has a type:** text, number, date, link, checkbox, one choice, many choices or person.
3. **Choice columns pick from a list of pills.** A new pill is added once, with its color (the same pill color picker as the Noun ERP), and after that everyone picks it. No spelling variants.
4. **A column belongs to the space, not to one week.** Add it once and every week in that space has it.
5. **Renaming keeps the data, and removing a column archives it.** Nothing is ever truly deleted.
6. **Each column has a one line note** saying what it is for, so the future AI knows what it means.

## Already decided and built in from the start (not parked)
- **Custom statuses.** The content team's five statuses are the prebuilt set. More can be added from the dropdown, each a pill with a color from the ERP's pill color picker. Every status sits in a stage (planning, shooting, editing, review, ready, posted) so automation and reports keep working.
- **Fixed columns can still differ by space.** Founder content has How to film, Shoot batch and What you need; the main calendar does not.
- **A to do list** can live inside a space.
